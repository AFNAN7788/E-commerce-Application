# AGENTS.md

## Core Commands

```bash
npm install          # Install dependencies
npm run dev          # Start Vite dev server
npm run build        # Create production build
npm run lint         # Run ESLint
npm run preview      # Preview production build
```

## Lint / Build

- Lint: `npm run lint` (ESLint flat config, errors should be zero)
- Build: `npm run build` (must succeed with zero warnings)
- No TypeScript — project is plain JS/JSX
